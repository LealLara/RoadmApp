App para organizar estudos, tarefas e metas com mais clareza e produtividade. Inclui recursos como agenda, quadros estilo kanban e flashcards. Atualmente em fase inicial.
 
Instalados os pacotes NuGet:
BCrypt.Net-Next
FluentValidation
cuidado com o Swashbuckle.AspNetCore usa version 6.5.0
Microsoft.EntityFrameworkCore.Tools
Microsoft.EntityFrameworkCore.Sqlite
Microsoft.AspNetCore.Authentication.JwtBearer
Desenvolvida utilizando C# e .NET 8.0, com arquitetura MVC e Entity Framework Core para gerenciamento de dados. O projeto é open-source e está disponível para contribuições e feedbacks.
